# Сообщения Карине — Telegram-бот

Бот принимает текст от пользователя и отправляет Карине два сообщения:

1. Красивое оформление без информации об авторе.
2. Отдельное уведомление с Telegram `@username` автора и исходным текстом. Если username у автора не задан, бот честно укажет это.

**Важно:** сообщения не полностью анонимны. Бот предупреждает об этом в `/start`; дополнительное подтверждение перед каждой отправкой не требуется.

## Локальный запуск

Требуется Python 3.10 или новее.

1. Создайте бота через [@BotFather](https://t.me/BotFather), отправьте `/newbot` и сохраните выданный токен.
2. Узнайте числовой Telegram chat ID Карины. Например, Карина может написать `@userinfobot` и использовать показанный им ID. Она также должна сначала открыть вашего бота и нажать **Start**, иначе бот не сможет написать ей первым.
3. Создайте виртуальное окружение и установите зависимости:

   ```sh
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `KARINA_CHAT_ID`.
5. Запустите бота:

   ```sh
   python main.py
   ```

Не публикуйте `.env` и токен бота. Если токен случайно попал в публичное место, отзовите его через BotFather и создайте новый.

## Развёртывание на Render (бесплатный тариф)

Бот поддерживает webhook на Render Web Service. Render Free предоставляет ограниченные бесплатные веб-сервисы (сейчас 512 MB RAM); после периода без входящих HTTP-запросов бесплатный сервис может приостанавливаться, поэтому этот вариант подходит для хобби и тестирования, но не гарантирует непрерывную доступность. Актуальные ограничения проверьте в [документации бесплатного тарифа Render](https://render.com/docs/free) и на [странице цен](https://render.com/pricing).

### 1. Загрузите проект в GitHub

1. Создайте приватный репозиторий на GitHub.
2. Загрузите файлы проекта: `main.py`, `requirements.txt`, `.gitignore`, README и тесты.
3. **Не загружайте `.env`**: там секретный токен. Он исключён из Git через `.gitignore`.

### 2. Создайте бесплатный Web Service

1. Войдите в [Render Dashboard](https://dashboard.render.com/) и создайте **New → Blueprint Instance**.
2. Подключите GitHub и выберите репозиторий проекта, содержащий `render.yaml`.
3. Render покажет Blueprint из файла конфигурации. Подтвердите создание сервиса.
4. Введите значения `BOT_TOKEN` и `KARINA_CHAT_ID`, когда Render запросит секреты. `WEBHOOK_SECRET` генерируется автоматически.
5. Дождитесь успешного Deploy. Render автоматически задаёт `RENDER_EXTERNAL_URL` и `PORT`; бот использует их для webhook и HTTP-сервера.
6. Откройте адрес Render-сервиса в браузере: должна появиться надпись `Telegram bot is running.` Затем проверьте `/health` (ответ `ok`) и отправьте боту `/start` в Telegram.

Если Blueprints недоступен, создайте **New → Web Service** вручную и задайте значения по умолчанию из `render.yaml` (Runtime Python, `pip install -r requirements.txt`, `python main.py`, Free, Frankfurt, health check `/health`); добавьте `BOT_TOKEN`, `KARINA_CHAT_ID` и сгенерированный `WEBHOOK_SECRET` в Environment Variables.

Если ранее запущен экземпляр бота локально или на другом хостинге с тем же токеном, остановите его перед тестированием webhook.

## Команды

- `/start` — приветствие и предупреждение о том, что Карина увидит @username.
- `/cancel` — подсказка, что отправка прекращена; бот не ведёт пошаговый режим диалога, поэтому достаточно просто не отправлять текст.

Бот принимает текст, фотографии и голосовые сообщения. Для фото и голосовых Карина получает вложение сначала в анонимном оформлении, затем повторно вместе с отдельным уведомлением, которое раскрывает @username отправителя. Если у фото есть подпись, она указывается во втором уведомлении.
